# Приватные (ephemeral) сообщения в группе

## Зачем

В рабочей группе вопрос к базе знаний часто не должен светиться всем.
Telegram Bot API умеет **скрытые сообщения**: их видит только указанный `receiver_user_id`.

## Два режима

### 1. Ephemeral-команда `/ask` из меню

Когда пользователь выбирает `/ask` из списка команд бота (не набирает текст руками),
в update приходит `ephemeral_message_id`.

Тогда бот может ответить скрыто, передав:

```json
{
  "chat_id": -100...,
  "text": "…",
  "ephemeral_message_parameters": { "receiver_user_id": 123 },
  "reply_parameters": { "ephemeral_message_id": 456 }
}
```

Окно на ответ по этому id ограничено (порядка ~15 секунд на старт цепочки).
Поэтому шаблон сразу шлёт статус «Принял вопрос…», а потом **редактирует** то же
скрытое сообщение через `editEphemeralMessageText`.

### 2. Обычный текст: `/ask …` или `@bot …`

Такой апдейт **виден всем** в чате (это сообщение человека).
Скрытый **ответ** бота всё ещё возможен, если:

- бот — **администратор** группы, или
- вы всё же попали в сценарий с валидным ephemeral context.

Если скрытый ответ в группе отклоняется API (часто `REPLY_TO_INVALID`),
этот шаблон **не** публикует ответ в чат. Он уходит в **личку** пользователю.

## Матрица видимости

| Действие пользователя | Вопрос видят все | Ответ |
|---|---|---|
| `/ask` из меню команд | Нет | Скрытый в группе |
| Набрали `/ask вопрос` | Да | Скрытый (бот-админ) или личка |
| `@bot вопрос` | Да | Скрытый (бот-админ) или личка |
| Просто «вопрос» без команды/`@` | — | Игнорируется |

## Практика для продакшена

1. Добавьте бота в группу и выдайте права администратора (достаточно минимальных).
2. Зарегистрируйте команды: `python scripts/setup_commands.py`.
3. Попросите участников один раз открыть бота и нажать `/start` — иначе DM не доставится.
4. Ограничьте чаты через `ALLOWED_CHAT_IDS`.
5. Не делайте публичный fallback в группу, если контент чувствительный.

## Методы API, которые использует шаблон

- `sendMessage` + `ephemeral_message_parameters`
- `editEphemeralMessageText`
- `editMessageText` (для DM fallback)
- `setMyCommands` (регистрация `/ask`)
- `getUpdates` / `deleteWebhook` (polling)

Документацию полей сверяйте с актуальной [Telegram Bot API](https://core.telegram.org/bots/api).
